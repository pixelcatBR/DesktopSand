# DesktopSand

Olá, eu sou o pixelcatBR e eu criei um novo projeto chamado DesktopSand. Esse projeto é uma adaptação do famoso estilo de jogo de fallen sand mas pro mundo dos desktop overlays.

# Licença

esse projeto usa a licença MIT, leia o arquivo de licença para mais detalhes.
# Como instalar

1. Baixe as dependências

```
pip install PyQt6 --break-system-packages
```

2. execute o python(na mesma pasta do arquivo baixado)

```
python3 main.py
```

3. Crie um atalho no KDE(opicional)

configurações -> atalhos -> atalhos personalizados

comando:

```
bash -c 'python3 /caminho/para/o/seu/main.py'
```
